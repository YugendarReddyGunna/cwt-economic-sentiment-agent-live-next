# Submission checklist

- [ ] Run the demo pipeline and tests.
- [ ] Configure and verify the selected Apify actor's input and output schema.
- [ ] Verify publication timestamps and source coverage from Tavily/Exa.
- [ ] Supply genuine timestamped strategy returns before interpreting real predictive/trading metrics.
- [ ] Audit all features for look-ahead bias.
- [ ] Understand and be able to explain every module before submission.
- [ ] Verify `.env` is ignored by Git and no secrets appear in commit history.
- [ ] Include the repository URL and setup instructions in the submission email.
- [ ] Share API credentials only through a secure channel if explicitly required; never publish tokens.
- [ ] Disclose synthetic data and limitations in the evaluation report.
